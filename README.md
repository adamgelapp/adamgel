# ADAMgel

Public showcase and resource library at https://adamgel.com.

Cloudflare Workers Static Assets serves `public/`. The existing Workers Builds connection deploys the `main` branch using `npx wrangler deploy`. No build command is required.

Run `npm install`, then `npm run dev` for local preview. Run `npm run check` to validate local links and resource files. Edit `public/index.html` for content, `public/styles.css` for presentation and `public/app.js` for search and gallery behaviour.

Source materials and photographs were supplied by the project owner. Draft materials are explicitly labelled. Publication links go to their original sources. No licence for third-party publications is implied. The website uses no analytics, tracking cookies, contact forms or external font services.
